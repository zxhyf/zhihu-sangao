# 一、患病规模

- 中国心血管病现患人数约 3.3 亿，其中高血压约 2.45 亿，是患病人数最多的慢性病（《中国心血管健康与疾病报告》，国家心血管病中心，年度更新）
- 18 岁及以上居民高血压患病率约 27.5%（《中国居民营养与慢性病状况报告（2020年）》，国家卫生健康委）
- 18 岁及以上居民糖尿病患病率约 11.9%；糖尿病前期人群规模更大（同上）
- 中国成人血脂异常总体患病率约 35.6%，其中以低 HDL-C 和甘油三酯升高为主（《中国血脂管理指南》引用的全国调查数据）
- 国际口径：中国是全球糖尿病患者数最多的国家（IDF Diabetes Atlas，每 2–3 年更新）

# 二、“三高”共病的普遍性

高血压、糖尿病、血脂异常三者常同时存在，且相互放大风险：
- 高血压患者中合并血脂异常的比例很高，合并糖代谢异常者亦常见
- 糖尿病患者的血压、血脂控制往往同时不达标
- 三者叠加使动脉粥样硬化性心血管疾病（ASCVD）风险成倍增加

这决定了单病种管理模式的天花板：把血压、血糖、血脂拆到三个科室、三个 App，就看不见交叉影响。

# 二·五、三高共病具体有哪些危害

- 高血压 + 糖尿病：脑卒中风险成倍增加，糖尿病肾病进展更快，眼底病变更早出现
- 高血压 + 血脂异常：动脉粥样硬化加速，冠心病、心肌梗死风险显著升高
- 糖尿病 + 血脂异常：甘油三酯升高、HDL-C 降低的“糖尿病性血脂异常”很常见，进一步加重血管损伤
- 三者叠加：心梗、脑卒中、心力衰竭、慢性肾脏病、外周动脉疾病的综合风险远高于单一疾病

共病还会带来“治疗冲突”：降压药可能影响血糖，降糖药可能影响体重，降脂药需要监测肝功能，多药同服带来相互作用。这正是单病种管理难以覆盖的部分。

# 三、“知晓率—治疗率—控制率”的缺口

以高血压为例，我国呈现典型的“三低”：
- 知晓率约 51.6%
- 治疗率约 45.8%
- 控制率约 16.8%

（数据来源：《中国心血管健康与疾病报告》引用的全国监测结果，具体年份以报告原文为准）

糖尿病、血脂异常的知晓率与控制率同样偏低，血脂异常尤其突出——很多人根本不知道自己血脂高。

# 四、疾病负担

- 心脑血管疾病位居我国居民死亡原因首位，占总死亡的四成以上
- 高血压是脑卒中、冠心病、心力衰竭、慢性肾脏病最重要的可干预危险因素
- 糖尿病并发症（视网膜病变、肾病、神经病变、糖尿病足）造成沉重的家庭照护负担
- 长期用药、反复住院、失能照护构成显著的直接与间接经济负担

# 五、政策背景：从“单病种”到“三高共管”

- 国家基本公共卫生服务项目已将高血压、糖尿病患者健康管理纳入，要求每年至少 4 次随访 + 1 次健康体检
- “三高共管、六病同防”是当前国家与多省正在推进的基层慢性病一体化服务模式（如山东省卫生健康委相关部署、各地实践报道），强调同步管理血压、血糖、血脂，同步筛查并发症
- 本项目正卡在这一模式的信息化缺口上：基层医生需要的是“一次随访同时看清三高 + 用药 + 依从性”的工具，而不是三套互不相通的系统

# 六、对本项目的启示

1. 目标人群基数大、病程长、复诊频次高——适合做长期陪伴型智能体，而不是一次性问诊工具
2. 控制率低的根因不只是“没好药”，更是“没记录、没反馈、没人管”——这恰好是 AI 智能体能补的位置
3. 家庭场景（子女远程照护）付费意愿最强，是可持续的落地路径
4. 一切都必须在“不做诊断、不开处方”的边界内完成
