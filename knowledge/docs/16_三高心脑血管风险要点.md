# 一句话结论
三高真正可怕的是心梗和脑卒中。**风险高低不是只看某一项指标**，而是看“有没有得过、有没有糖尿病、有没有肾病、吸不吸烟、年龄多大”合起来判断，所以 LDL-C 的目标值要由医生定。

# 一、医生用什么判断风险

主要看这几件事（中国血脂管理指南 2023 的分层思路）：

- 有没有得过心梗、脑卒中、放过支架或做过搭桥（**已患病者属于最高风险**）
- 有没有糖尿病（尤其病程长、有并发症者）
- 有没有慢性肾脏病
- 血压、血脂、血糖控制得怎么样
- 吸不吸烟、年龄、有没有肥胖

分级一般分为低危、中危、高危、极高危、超高危，**分层由医生判定**，本系统不做分层。

# 二、LDL-C 目标值为什么因人而异

同样是 3.4 mmol/L，对健康人是正常的，对得过心梗的人就明显偏高。指南按风险给不同目标（一般人群 <3.4，高危 <2.6，极高危 <1.8，超高危 <1.4 mmol/L，且需较基线明显下降）。

所以：**看到 LDL-C“在参考范围内”不等于达标**，要问医生“我的目标是多少”。

# 三、日常能做的四件事

1. **把血压、血糖、血脂的记录带给医生**，这比单次化验单有用
2. **戒烟**：对心脑血管的风险改善最快
3. **吃动平衡**：少盐少油、每周累计 150 分钟中等强度活动（快走、骑车、太极拳）
4. **按医嘱吃药**：他汀、降压药、抗血小板药不能因为“感觉好了”就停

# 四、这些症状要当成“警报”

- 活动后胸闷、胸痛，休息几分钟缓解（心绞痛可能）
- 突然说话不清、一侧手脚无力、口角歪斜、看东西重影（卒中，立即 120）
- 突然剧烈头痛、呕吐、意识不清（立即 120）
- 一条腿突然肿痛（警惕血栓）
- 夜间不能平卧、憋醒（心功能可能受影响）

记住发病时间，越早到医院，能做的治疗越多。

# 五、复查要关注的指标

- 血脂四项（尤其 LDL-C）
- 血压（家庭自测记录）
- 血糖、HbA1c
- 肝肾功能（吃他汀者）
- 心电图，必要时心脏超声、颈动脉超声

# 六、本页不回答什么

本页只做风险科普和复查提醒，**不做风险分层、不给降脂目标、不建议用不用抗血小板药**。这些必须由医生结合完整资料决定。
