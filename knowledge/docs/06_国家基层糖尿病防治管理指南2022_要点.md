# 一、适用范围

用于基层医疗卫生机构开展 2 型糖尿病患者的健康管理，是国家基本公共卫生服务项目"糖尿病患者健康管理"的技术依据。

# 二、基层诊断与分型

以空腹血糖、OGTT 2 小时血糖或 HbA1c 作为诊断依据（标准同国家指南）。基层应识别需要转诊的情况：1 型糖尿病、妊娠糖尿病、特殊类型糖尿病、血糖控制困难、反复低血糖、严重并发症。

# 三、基层控制目标

- 空腹血糖 4.4–7.0 mmol/L
- 非空腹血糖 <10.0 mmol/L
- HbA1c <7.0%（老年、有并发症者可放宽至 <8.0%）
- 血压 <130/80 mmHg
- LDL-C <2.6 mmol/L（合并 ASCVD 者 <1.8 mmol/L，需医生评估）
- BMI <24 kg/m²

# 四、随访管理

- 血糖控制满意、无药物不良反应：每 3 个月随访 1 次
- 血糖控制不满意或出现不良反应：2 周内随访
- 连续 2 次随访血糖控制不满意：建议转诊
- 每年至少 1 次全面健康检查（含眼底、尿白蛋白、足部、血脂、血压、心电图）
- 每年至少 4 次面对面随访 + 1 次健康体检（国家基本公共卫生服务要求）

# 五、基层用药

基层可选药物：二甲双胍、磺脲类、α-糖苷酶抑制剂、DPP-4 抑制剂、胰岛素等。

- 二甲双胍为一线首选，若无禁忌应贯穿治疗全程
- 小剂量起始，逐渐加量，减少胃肠道反应
- 老年患者、肾功能不全者优先选择低血糖风险低的药物
- 使用胰岛素者需培训注射技术、低血糖识别与处理
- 药物调整必须由医生完成

# 六、转诊指征

- 血糖 ≥16.7 mmol/L 或出现酮症（恶心呕吐、腹痛、呼吸有烂苹果味）
- 反复发生低血糖（<3.9 mmol/L）
- 出现急性并发症：糖尿病酮症酸中毒、高渗高血糖状态、低血糖昏迷
- 新出现或加重慢性并发症：视力下降、大量蛋白尿、足部溃疡、肢体麻木疼痛
- 妊娠、严重感染、手术等应激状态

# 七、糖尿病足预防要点（基层重点）

- 每日检查双足，尤其足底和趾间
- 温水洗脚，水温 <37 ℃，先用手肘试温
- 不赤脚行走，鞋袜合脚、无接缝压迫
- 不自行修剪胼胝、鸡眼，不用热水袋、暖宝宝直接接触足部
- 出现破损、水疱、颜色改变立即就医

# 八、健康教育要点

- 会算主食量，会看食品标签
- 会自测血糖并记录
- 会识别和处理低血糖
- 知道什么情况必须去医院
- 知道糖尿病是"可控不可怕"的长期管理疾病
