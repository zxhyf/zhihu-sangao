# 一、血脂检测项目与合适水平

基本检测项目为：总胆固醇（TC）、甘油三酯（TG）、低密度脂蛋白胆固醇（LDL-C）、高密度脂蛋白胆固醇（HDL-C）。40 岁以上成年人建议每年检测一次血脂；三高共病患者建议每 3–6 个月检测一次。

| 指标 | 合适水平 | 边缘升高 | 升高 |
|---|---|---|---|
| TC（mmol/L） | <5.2 | 5.2–6.2 | ≥6.2 |
| LDL-C（mmol/L） | <3.4 | 3.4–4.1 | ≥4.1 |
| TG（mmol/L） | <1.7 | 1.7–2.3 | ≥2.3 |
| HDL-C（mmol/L） | ≥1.0 | — | 降低：<1.0 |

甘油三酯 ≥5.6 mmol/L 为严重升高，急性胰腺炎风险明显增加，需要尽快就医评估。

# 二、LDL-C 分层目标（核心）

LDL-C 是动脉粥样硬化性心血管疾病（ASCVD）最重要的致病性危险因素，临床以 LDL-C 为首要干预靶点。

| 风险分层 | LDL-C 目标值（mmol/L） |
|---|---|
| 低危 | <3.4 |
| 中危 | <3.4 |
| 高危 | <2.6 |
| 极高危 | <1.8 且较基线降低 ≥50% |
| 超高危 | <1.4 且较基线降低 ≥50% |

风险分层由医生依据是否已患 ASCVD、危险因素数量、靶器官损害等综合判定。本系统不计算个人风险分层，只提示“该指标超出指南一般参考范围，建议由医生确定个人目标”。

# 三、生活方式干预

- 减少饱和脂肪和反式脂肪：少吃肥肉、动物内脏、油炸食品、人造奶油、起酥点心
- 每日烹调油 25–30 g，优先植物油，避免反复煎炸
- 增加膳食纤维：每日蔬菜 300–500 g、全谷物 50–150 g、豆类
- 每周吃 2 次鱼类（富含 n-3 多不饱和脂肪酸）
- 限制精制糖和含糖饮料，果糖会升高甘油三酯
- 体重管理、规律运动、戒烟限酒
- 甘油三酯升高者尤其要严格限制酒精和精制碳水

# 四、药物治疗原则（供理解，不用于自行调药）

他汀类是降 LDL-C 的基石药物，中等强度他汀可使 LDL-C 降低 30%–50%。常用中等强度剂量：阿托伐他汀 10–20 mg，瑞舒伐他汀 5–10 mg，辛伐他汀 20–40 mg。若单药不达标，可联合胆固醇吸收抑制剂（依折麦布）或 PCSK9 抑制剂。

## 用药监测
首次用药或调整剂量后 4–6 周复查血脂、肝功能（ALT/AST）和肌酸激酶（CK），达标后每 3–6 个月复查一次。出现不明原因的肌肉酸痛、乏力、酱油色尿时应及时就医。

## 联合用药注意
他汀与贝特类（尤其是吉非贝齐）联合使用会增加肌病和肝损伤风险，必须由医生评估并监测。他汀与某些大环内酯类抗生素、唑类抗真菌药、胺碘酮、维拉帕米、环孢素合用可升高他汀血药浓度，增加肌病风险。服用他汀期间应避免大量饮用西柚汁。

# 五、需要警惕的情况

- 甘油三酯 ≥5.6 mmol/L，或伴剧烈上腹痛、向背部放射、恶心呕吐：警惕急性胰腺炎，立即就医
- 服用他汀后出现明显肌痛、肌无力、尿色变深：立即就医并告知用药史
- 严重肝病患者、妊娠期女性降脂方案需专科医生评估
