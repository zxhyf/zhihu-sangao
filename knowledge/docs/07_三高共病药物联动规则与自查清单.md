# 一、为什么要做“药物—代谢”联动

三高（高血压、高血糖、高血脂）常常同时存在，患者平均同时服用 5 种以上药物。分科开药时，各科医生往往只看到自己那一科的问题，而药物之间的相互影响、以及对血糖/血压/血脂/尿酸的代谢影响，恰恰发生在“科与科之间”。

本文件把这些交叉点整理成可查询、可解释、可溯源的规则，是本项目区别于单病种 App 的核心技术资产。

# 二、六类需要特别关注的代谢影响

## 1. 噻嗪类利尿剂（氢氯噻嗪、吲达帕胺）——升糖、升尿酸
可能升高血糖、升高血尿酸、轻度升高甘油三酯，并引起低钾血症。合并糖尿病者需加强血糖监测；高尿酸或痛风者慎用。与 β 受体阻滞剂联用时，新发糖尿病风险进一步增加。

## 2. β 受体阻滞剂（美托洛尔、比索洛尔）——掩盖低血糖
低血糖的预警症状里，心慌、手抖、震颤由交感神经介导，而 β 受体阻滞剂正好阻断这些信号，只留下出汗。使用胰岛素或磺脲类药物的患者，可能在没有心慌手抖的情况下直接进入严重低血糖。这是最容易被忽视、后果最严重的一条。

## 3. 他汀 + 贝特——肌病与肝损伤
他汀与非诺贝特联合使用会增加肌病和肝损伤风险，必须由医生评估并监测肌酸激酶与肝功能。此外，他汀与克拉霉素、唑类抗真菌药、胺碘酮、维拉帕米、环孢素合用，或大量饮用西柚汁，都会升高他汀血药浓度。

## 4. ACEI/ARB——高钾与肾损伤
ACEI 与 ARB 不推荐联合使用。二者与螺内酯、补钾剂、低钠富钾盐合用有高钾风险；与布洛芬等 NSAIDs 合用会削弱降压效果并增加肾损伤；ACEI/ARB + 利尿剂 + NSAID 被称为“三重打击”，可诱发急性肾损伤。

## 5. 降糖药——低血糖的连锁反应
胰岛素和磺脲类是低血糖风险最高的药物。SGLT2 抑制剂（达格列净等）与胰岛素或磺脲类联用需减量；阿卡波糖所致低血糖必须用葡萄糖纠正（蔗糖起效慢）；SGLT2 抑制剂在禁食、手术、严重感染时可引起正常血糖性酮症酸中毒。

## 6. 常见“隐形”药物与食物
- 复方甘草片、含甘草的止咳糖浆和润喉糖：假性醛固酮增多，低钾、血压升高
- 含麻黄碱/伪麻黄碱的复方感冒药：升高血压、心率、血糖
- 布洛芬等止痛药：升高血压、削弱降压药、损伤肾脏
- 西柚汁：升高他汀和部分 CCB 血药浓度
- 低钠富钾盐：与 ACEI/ARB、螺内酯合用有高钾风险
- 糖皮质激素：升高血糖、血压、血脂

# 三、患者自查清单（可直接用于随访）

1. 我现在一共在吃几种药？分别治什么？
2. 有没有同时吃两种降压药（例如 ACEI 和 ARB）？
3. 有没有在吃止痛药、感冒药、止咳药？吃了多久？
4. 是否在用低钠盐？血钾最近查过吗？
5. 有没有出现肌肉酸痛、乏力、尿色变深？
6. 有没有出现过心慌、手抖、出冷汗？当时血糖多少？
7. 最近一次查肝肾功能、血脂、糖化血红蛋白是什么时候？

# 四、系统如何使用这份规则

用户在对话中提到药物时，系统会：
1. 从自然语言中识别药名（含商品名、别名）；
2. 匹配药物—药物、药物—食物规则；
3. 输出“需要关注什么 + 需要监测什么 + 该向医生问什么”；
4. 明确标注：不提供剂量建议，不判断能否一起吃，最终判断由医生完成。

# 五、边界声明

本规则表用于健康管理提示和就医沟通准备，不构成用药建议，不能替代药师审核和医生处方。任何加药、减药、换药、停药的决定都必须由医生做出。
