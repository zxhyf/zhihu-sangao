# 一句话结论
高血压和糖尿病都会伤肾，而肾不好又会反过来推高血压、让部分药物需要调整。**每年查一次尿微量白蛋白和肾功能**，是发现早期肾损伤最划算的办法。

# 一、怎么发现肾受累（早期往往没感觉）

- **尿微量白蛋白/肌酐比值（ACR）**：最早出现异常的指标
- **血肌酐 + eGFR**：估算肾小球滤过率，反映肾功能分级
- **尿常规**：看有没有蛋白、红细胞
- 早期肾损伤通常**没有症状**，等到水肿、乏力、夜尿多，往往已经不是早期

建议：糖尿病者每年至少查一次 ACR 和 eGFR；已有异常者按医生安排缩短间隔。

# 二、血压和血糖的目标更严

- 合并慢性肾脏病的高血压患者，指南建议血压降至 **<130/80 mmHg**，但要缓慢平稳
- 糖尿病合并肾病者，血糖控制目标由医生根据年龄、病程、低血糖风险个体化确定
- 具体目标以您的医生判断为准，本系统不给个人目标值

# 三、饮食上要注意的三件事

1. **盐**：每日食盐 <5 g，这一点在肾病更重要（水肿、血压都受盐影响）
2. **蛋白质**：不要自行高蛋白饮食，也不要不吃蛋白；量由医生或营养师按肾功能定
3. **钾和磷**：肾功能下降时可能需要限制，**但必须在医生指导下**，不要自行买低钠盐（低钠盐常含钾）

# 四、用药上要特别小心

- **非甾体抗炎药（止痛药）**：尽量不用，可能加重肾损伤
- **部分中成药、保健品**：成分不明，可能含伤肾成分
- **造影检查**：做增强 CT 前主动告诉医生有肾病
- **二甲双胍**：肾功能明显下降时需由医生评估是否继续
- **普利类/沙坦类**：对肾有保护作用，但需要医生监测血钾和肌酐，**不要自行加量或停药**

所有调整都由医生决定。

# 五、出现这些情况尽快就医

- 尿中泡沫明显增多且久久不散
- 眼睑或下肢水肿，按压有凹陷
- 夜尿次数明显增多、尿量减少
- 乏力、食欲差、恶心（可能是肾功能下降的表现）
- 血钾异常（化验单标红）

# 六、本页不回答什么

本页只做筛查提醒和生活方式说明，不判断肾功能分期，不给药物剂量调整建议。肾功能相关问题请以肾内科医生的意见为准。
