# 一、血压

单位 mmHg，写作“收缩压/舒张压”，例如 135/85。收缩压是心脏收缩时动脉内的最高压力，舒张压是心脏舒张时的最低压力。

- 单次升高不等于高血压，要看非同日多次测量
- 家庭血压阈值（135/85）低于诊室血压阈值（140/90）
- 早晨起床后 1 小时内、服药前、排尿后、早餐前测量最能反映真实水平
- 左右臂血压可相差 5–10 mmHg，首次测量应测双臂，以后固定测较高的一侧
- 血压波动是正常的，情绪、疼痛、憋尿、寒冷、咖啡都会影响

# 二、血糖

单位 mmol/L。

| 检测类型 | 正常 | 糖尿病前期 | 糖尿病 |
|---|---|---|---|
| 空腹血糖 | 3.9–6.1 | 6.1–6.9 | ≥7.0 |
| 餐后 2 小时 | <7.8 | 7.8–11.0 | ≥11.1 |
| 随机血糖 | <7.8 | — | ≥11.1（伴症状） |
| HbA1c | <5.7% | 5.7%–6.4% | ≥6.5% |

低血糖：<3.9 mmol/L；严重低血糖：≤3.0 mmol/L。

# 三、血脂四项

| 指标 | 中文名 | 合适水平 | 说明 |
|---|---|---|---|
| TC | 总胆固醇 | <5.2 mmol/L | 各项胆固醇总和 |
| TG | 甘油三酯 | <1.7 mmol/L | 受饮食和酒精影响大，需空腹 12 小时抽血 |
| LDL-C | 低密度脂蛋白胆固醇 | <3.4 mmol/L（一般人群） | “坏胆固醇”，是首要干预靶点，目标值按风险分层 |
| HDL-C | 高密度脂蛋白胆固醇 | ≥1.0 mmol/L | “好胆固醇”，偏低是风险因素 |

LDL-C 的目标值取决于个人心血管风险分层：低危/中危 <3.4，高危 <2.6，极高危 <1.8，超高危 <1.4 mmol/L，且需较基线降低 ≥50%。分层由医生判定。

# 四、体重与腰围

- BMI = 体重(kg) ÷ 身高(m)²
- 中国成人：BMI <18.5 偏瘦；18.5–23.9 正常；24.0–27.9 超重；≥28.0 肥胖
- 腰围：男性 <90 cm，女性 <85 cm；中心性肥胖比体重更能反映代谢风险
- 测量腰围：站立，双脚分开 25–30 cm，软尺经肚脐上方、髂前上棘水平绕一周，呼气末读数

# 五、糖化血红蛋白（HbA1c）

反映近 2–3 个月的平均血糖水平，不受当天饮食影响，无需空腹。多数成人糖尿病患者控制目标 <7.0%，具体由医生根据年龄、病程、并发症和低血糖风险个体化确定。贫血、血红蛋白病、近期输血会影响结果准确性。

# 六、如何读一张检验单（实操）

> 配套阅读：怎么量、怎么记 → 《家庭血压测量与记录实操》；多久复查、复查带什么 → 《三高复查与随访清单》。

1. 先看“参考范围”列：不同医院、不同检测方法范围略有差异，以报告单标注为准
2. 看箭头：↑ 高于参考上限，↓ 低于下限，但不等于一定有病
3. 看趋势比看单次数值更重要：一次轻度异常，通常需要复查确认
4. 把同一指标的多次结果按时间排开（本系统会自动画趋势图）
5. 带上检验单和用药清单一起看医生，比单独看一项指标有用得多

# 七、需要记录的关键信息

每次测量记录：**时间、数值、单位、当时的场景**（空腹/餐后几小时/服药前/运动后/情绪紧张）、以及当天是否漏服药。这些“场景信息”往往比数值本身更能解释波动。

# 八、判读之后的下一步

判断完数值，通常只有三种去向，对照着做就行：

| 结果 | 下一步 | 看哪篇 |
|---|---|---|
| 在参考范围内 | 按原计划继续记录，按时复查 | 《三高复查与随访清单》 |
| 轻度超出、没有不适 | 同一时间复测 2–3 次，记录下来，下次复诊给医生看 | 《家庭血压测量与记录实操》 |
| 明显超出或伴不适 | 按《三高急症识别与就医指征》的分流表决定是 120、当天就医还是预约门诊 | 《三高急症识别与就医指征》 |

本页只解释“数值怎么看”，不判断您是否需要调整药物。
