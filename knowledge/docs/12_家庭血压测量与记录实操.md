# 一句话结论
家庭自测血压要用**上臂式**电子血压计，坐着歇 5 分钟再量，早晚各一次、每次量 2–3 遍取平均，并且把“什么时候量的、量之前做了什么”一起记下来。

# 一、设备怎么选

- 选**上臂式**电子血压计，不选腕式、指式（误差大）
- 袖带要合臂围：袖带太小会把血压量高，太大则量低
- 血压计每年校一次；摔过、进水后不要再用
- 血糖仪试纸注意有效期，开封后按说明保存

# 二、量之前要做的 5 件事

1. 先排尿，憋尿会让血压升高
2. 静坐 5 分钟，不说话、不看手机
3. 30 分钟内不吸烟、不喝咖啡或浓茶
4. 坐有靠背的椅子，双脚平放、不翘腿
5. 上臂裸露或只穿薄衣，袖带下缘距肘窝 2–3 cm，与心脏同高

# 三、量几次、什么时候量

- **早晨**：起床后 1 小时内、服药前、早餐前、排尿后
- **晚上**：睡前
- 每次连续量 2–3 遍，每遍间隔 1 分钟，取平均值记录
- 血压稳定时，每周至少量 3–4 天；刚调药、刚出现不适时连续量 5–7 天

# 四、记录要写清“场景”

只记数字，医生很难判断。每次记录建议包含：

| 项目 | 例子 |
|---|---|
| 日期时间 | 11-03 06:40 |
| 数值 | 152/94 mmHg |
| 脉搏 | 78 次/分 |
| 场景 | 起床后、服药前、昨夜睡得晚 |
| 当天服药 | 已服 / 漏服 |

场景信息往往比数值本身更能解释波动。

# 五、最常见的 6 个错误

1. 量之前刚爬完楼、刚抽完烟
2. 说话、翘腿、袖带隔着一层厚衣服
3. 只量一次就下结论
4. 只量一侧手臂（首次应测双臂，之后固定量较高的一侧）
5. 数值一高就反复量十几次（越紧张越高）
6. 白天随时量，和“清晨血压”“睡前血压”混在一起比较

# 六、哪些情况要加测

- 头晕、头胀、心慌、眼前发黑时
- 刚开始吃降压药、或医生刚调过药的第一周
- 感冒发热、腹泻、明显失眠之后
- 天气骤冷、情绪激动、熬夜之后

# 七、本页不回答什么

本页只讲“怎么量、怎么记”，不判断您是不是高血压，也不给用药建议。血压持续偏高或伴随不适，请及时就医。
