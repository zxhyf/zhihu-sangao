# 一句话结论
三高不是“看一次就好”的病。**平时自己测、按医生定的时间复查、每年做一次并发症筛查**，这三件事决定了长期是否安全。

# 一、各项指标多久看一次

| 项目 | 自己在家 | 到医院 |
|---|---|---|
| 血压 | 每周至少 3–4 天，早晚各一次 | 按医生安排，一般 1–3 个月一次；刚调药时更密 |
| 空腹/餐后血糖 | 按医生定的频次，通常每周 2–4 次，含空腹和餐后 | 按医生安排 |
| 糖化血红蛋白（HbA1c） | — | 一般每 3 个月一次；长期稳定者医生可能放宽到 6 个月 |
| 血脂四项 | — | 开始或调整降脂药后通常 4–12 周复查；稳定后每 3–6 个月 |
| 肾功能、尿微量白蛋白 | — | 至少每年一次；已有肾病者按医生安排 |
| 眼底 | — | 糖尿病者至少每年一次 |
| 足部检查 | 每天自己看脚 | 每年一次，由医护检查感觉和血供 |

具体时间以您的医生安排为准，上表只是常见做法。

# 二、每年一次的“并发症筛查”查什么

- **眼底**：糖尿病视网膜病变是成年人失明的主要原因之一，早期没有感觉
- **肾脏**：尿微量白蛋白/肌酐比值（ACR）+ 血肌酐算 eGFR
- **足部**：皮肤破损、鸡眼、感觉减退、足背动脉搏动
- **心脏**：心电图，必要时心脏超声
- **血管**：颈动脉超声（医生判断是否需要）

这些检查正常时也建议留档，第二年对比才有意义。

# 三、复诊要带什么（照这个清单准备）

1. 近 2–4 周的血压/血糖记录（手机截图或本子都行）
2. 当前在吃的所有药：药名、剂量、每天几次（**包括保健品和中成药**）
3. 最近一次检验单（血糖、血脂、肾功能、尿常规）
4. 想问医生的 3 个问题，提前写下来
5. 出现过的症状：什么时候、持续多久、当时在做什么

带着清单去，5 分钟能说完；不带清单，往往说不到重点。

# 四、哪些情况不用等预约，尽快去

- 血压连续 3 天 ≥160/100 mmHg
- 空腹血糖连续 3 天 ≥11.1 mmol/L，或反复低血糖
- 新出现水肿、夜间不能平卧、活动后气短
- 肌肉酸痛伴尿色变深（吃他汀者）
- 足部破溃、水疱、发黑
- 体重 1 个月内无意下降超过 5%

# 五、记录不足时该怎么办

如果最近几乎没有记录，本系统会直接说明“记录不足，暂时无法判断趋势”，不会替您推测。此时最有用的一件事是：**从今天开始，连续记 3–7 天**，再去复诊。

# 六、本页不回答什么

本页只说明“什么时候查、查什么、带什么”，不判断您是否需要调整药物，也不替代医生的随访安排。
