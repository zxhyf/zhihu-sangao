# 一、适用范围

面向基层医疗卫生机构（社区卫生服务中心、乡镇卫生院、村卫生室）的高血压患者管理，是国家基本公共卫生服务项目"高血压患者健康管理"的技术依据，也是"三高共管、六病同防"基层慢性病一体化服务模式的核心文件之一。

# 二、基层筛查与诊断

18 岁及以上成年人每年至少测一次血压。首诊血压 ≥140/90 mmHg 者，建议非同日 3 次复测确认。基层可采用家庭血压（≥135/85 mmHg）辅助诊断。

# 三、基层降压目标

一般患者 <140/90 mmHg；能耐受者 <130/80 mmHg。65 岁及以上老年人 <150/90 mmHg，耐受者可 <140/90 mmHg。

# 四、基层用药原则

基层可选用的五类降压药物：CCB、ACEI、ARB、利尿剂、β 受体阻滞剂。

- 小剂量起始，优先选用长效制剂，每日 1 次
- 单药控制不佳时推荐联合用药，优先推荐 CCB + ACEI/ARB，或利尿剂 + ACEI/ARB
- 不推荐 ACEI 与 ARB 联合
- 老年单纯收缩期高血压优先 CCB 或利尿剂
- 合并糖尿病、蛋白尿者优先 ACEI/ARB
- 合并冠心病、心力衰竭、心率快者可用 β 受体阻滞剂

# 五、随访管理（分级随访）

- 血压控制满意（<140/90 mmHg）且无不良反应：每 3 个月随访 1 次
- 血压控制不满意：2 周内随访，调整用药后再次评估
- 出现药物不良反应：2 周内随访
- 连续 2 次随访血压控制不满意，或出现不良反应难以耐受：建议转诊
- 每年进行 1 次较全面的健康检查

每次随访记录：症状、血压、心率、生活方式（吸烟、饮酒、运动、摄盐）、服药依从性、药物不良反应。

# 六、转诊指征

- 血压 ≥180/110 mmHg，或伴胸痛、呼吸困难、意识改变、剧烈头痛、视物模糊
- 疑似继发性高血压（年轻起病、血压难以控制、伴低血钾、阵发性血压升高伴心悸出汗）
- 妊娠期高血压
- 药物不良反应不能耐受
- 出现新的并发症或靶器官损害

# 七、依从性管理（基层实践建议）

- 简化方案：优先每日 1 次的长效制剂，减少服药次数
- 使用分药盒、手机提醒、家庭成员监督
- 每次随访强化"为什么吃药"，而不只是"记得吃药"
- 家庭医生签约服务与随访结合，提高长期随访率

# 八、三高共管

高血压、糖尿病、血脂异常常合并存在，基层应推行"三高共管"，同步管理血压、血糖、血脂，同一次随访完成多项指标记录与评估，避免分科割裂。同时开展 ASCVD 风险评估、并发症筛查和健康宣教。
