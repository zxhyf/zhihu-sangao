# 一句话结论
药要按医生开的剂量和时间吃。**漏服了不要加倍补**；出现新症状先想到“是不是药的反应”，把药盒和症状一起带给医生看。

# 一、漏服了怎么办（通用原则）

1. 想起来时，如果**离下次服药还很久**（超过两次服药间隔的一半），可以补服这一次
2. 如果**快到下次服药时间**，就跳过这一次，按原时间吃下一次
3. **无论哪种情况，都不要一次吃两倍的量**
4. 把漏服的时间记下来，复诊时告诉医生；偶尔漏一次通常问题不大，经常漏服需要和医生商量更简单的方案

不同药物的具体处理可能不同，拿不准时问医生或药师。

# 二、常见药物可能的不良反应（只做提醒，不做判断）

| 药物类别 | 可能出现的反应 | 该怎么做 |
|---|---|---|
| 普利类（ACEI，如依那普利） | 干咳、血钾升高 | 干咳影响睡眠时告诉医生，不要自行停药 |
| 沙坦类（ARB，如缬沙坦） | 头晕、血钾升高 | 监测血压和肾功能 |
| 地平类（CCB，如氨氯地平） | 踝部水肿、面部潮红、心跳快 | 水肿明显时就诊，不要自行停药 |
| 洛尔类（β 受体阻滞剂） | 心跳偏慢、乏力、手脚凉 | 不要突然停，需医生指导逐渐减量 |
| 利尿剂（如氢氯噻嗪） | 低钾、尿酸升高、口干 | 按医生安排复查电解质 |
| 二甲双胍 | 胃肠不适、腹泻 | 随餐或餐后服可减轻；肾功能明显下降时需医生评估 |
| 磺脲类（如格列美脲） | 低血糖（心慌、出汗、手抖、饿） | 随身带糖，反复发生要复诊 |
| 他汀类 | 肌肉酸痛、转氨酶升高 | 肌痛伴尿色变深要尽快就医 |

这些只是“可能”，出现不代表一定是药引起的；但把这些情况告诉医生，能帮他更快判断。

# 三、多药同服要注意什么

- 一张**用药清单**：药名、剂量、每天几次、什么时候吃，随身带
- 不同药的时间可以错开，但**不要自己改时间**，先问医生或药师
- 每次看不同科室，都主动说“我还在吃这些药”
- 每年请医生或药师做一次**用药重整**（看看有没有重复、能不能减）
- 老年人尤其注意：降压药 + 利尿剂 + 降糖药同时用，起身过快容易头晕跌倒

# 四、保健品、中成药和非处方药

- 成分不明的“降压茶”“降糖胶囊”不要替代药物
- 部分中成药含有利尿或影响凝血的成分，与西药同服可能叠加作用
- 感冒药里常有升压成分（如伪麻黄碱），高血压者买之前问药师
- 止痛药（尤其非甾体抗炎药）长期用会影响血压和肾功能
- 任何“停药试试”“偏方根治”的说法都不要信

# 五、服药与吃饭的关系（常见几类）

- 一般降压药：多数不受进食影响，固定时间吃即可，具体看说明书
- 二甲双胍：随餐或餐后服，减少胃肠反应
- 磺脲类：餐前服，服完要按时吃饭，否则易低血糖
- 他汀类：多数睡前服，具体以说明书和医嘱为准

# 六、什么时候联系医生或药师

- 出现新的、持续的不适（水肿、干咳、肌痛、心慌、乏力）
- 反复低血糖，或血糖、血压明显波动
- 需要加用其他药（包括中药、保健品）之前
- 记不清怎么吃、漏服多次、药快吃完了

# 七、本页不回答什么

本页只做风险提醒和复诊准备，**不给剂量、不建议停药或换药**。是否调整用药，必须由开药的医生结合您的完整情况决定。
