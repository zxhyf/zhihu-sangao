# 智护三高 · 三高共病 AI 健康管理智能体

> 面向 **高血压、高血糖、血脂异常**（俗称"三高"）人群及其家庭的可运行 AI Agent 原型。
> 以自然语言对话为唯一入口，把碎片化的健康数据变成能看懂的趋势、能执行的方案、能带去复诊的报告。

**参赛信息**：第二届全国人工智能应用创新大赛 · 通用赛道（命题方向「让 AI Agent 赋能千行百业」，领域：医疗）
**技术特点**：零第三方依赖（纯 Python 标准库 + 原生前端），克隆即可运行；DeepSeek 大模型可选，断网自动降级为本地规则引擎。

> ⚠️ 本系统为健康管理辅助工具，**不做诊断、不开处方、不调整药物剂量、不替代医生、不做急救判断**。
> 所有输出统一附「本建议不构成诊疗意见，请遵医嘱。」

## 一、30 秒跑起来

```bash
# 1. 进入项目目录
cd 三高

# 2. 启动（无需安装任何依赖）
python app.py
```

浏览器会自动打开 `http://127.0.0.1:8600`。也可以双击 `run.bat`（Windows）。

首次启动会自动完成三件事：
1. 创建 SQLite 数据库 `data/health.db`
2. 建立知识库索引（11 篇权威指南要点 → 100+ 个可检索片段）
3. 写入一组覆盖近 30 天的演示数据（可在侧栏提示条点「恢复」重灌）

**想接入真实大模型**：把 `.env` 里的 `DEEPSEEK_API_KEY` 换成自己的 Key 即可；
不配置 Key、或断网、或 API 报错时，系统会自动降级为本地规则引擎，**所有功能与演示流程仍然完整**。

### 两种运行模式

| 模式 | 启动方式 | 访问控制 |
|---|---|---|
| **本地单机**（默认） | `python app.py` | 只监听 127.0.0.1；首次访问自动发会话 Cookie，不需要密码。**没设密码时不允许对外监听**，传 `--host 0.0.0.0` 会被强制回退到本机 |
| **共享演示** | `set APP_PASSWORD=你的密码 && python app.py --host 0.0.0.0` | 先登录再使用；所有 `/api/*` 未登录返回 401；登录失败 5 次/5 分钟限流 |

> 把地址发给评委或部署到局域网/云主机时，**必须用共享演示模式**。
> 正式试用还可以设 `APP_ENV=prod`，此时不会自动写入演示数据。

### 评委体验模式（推荐用于评审）

`.env` 里设 `JUDGE_MODE=1`（仓库里已默认打开），会同时生效：

| 行为 | 说明 |
|---|---|
| **每个浏览器会话一份独立演示数据** | 首次打开自动生成 `u_demo_xxxx` 并灌入 71 条合成指标 + 3 种药，评委之间互不影响；48 小时无活动自动清理 |
| **隐藏全部管理入口** | 没有「演示数据 / 清空 / 指南库管理」，只剩下用户真正要用的功能 |
| **管理接口直接 403** | `/api/kb/upload`、`/api/kb/delete`、`/api/kb/reindex`、`/api/demo/seed`、`/api/demo/clear`、`/api/tools` 等，即使绕过界面直接请求也返回 403 |
| **默认本地规则引擎** | `PREFER_LOCAL=1`：不调大模型、不烧 token、断网也能完整跑；录演示视频想用大模型时改成 `0` |
| **大模型超时 12 秒** | 避免网络抖动把评委卡在等待界面 |
| **每会话限流 120 条/小时** | 防止公网被刷 |
| **页面常驻说明** | 首页写明「合成的演示数据」「当前引擎」「3 分钟测试路径」与推荐问题 |
| **恢复我的演示数据** | 侧栏提示条上的「恢复」：只重置自己这份，不动别人 |

自己维护知识库时把 `JUDGE_MODE` 关掉、`ENABLE_ADMIN_API=1`，管理接口即可用。

### 把链接发给别人看（三种方式）

| 方式 | 命令 | 对方打开 |
|---|---|---|
| 本机 | `python app.py` | `http://127.0.0.1:8600` |
| 局域网 | `python app.py --host 0.0.0.0 --password 你的密码` | `http://你的内网IP:8600/?k=你的密码` |
| **公网（推荐）** | 双击 `share.bat` | `https://xxxx.trycloudflare.com/?k=你的密码` |

`share.bat` 会依次完成：启动应用（带密码）→ 开 Cloudflare 临时隧道 → 把体验链接复制到剪贴板。
需要先下载 `cloudflared.exe` 放到 `bin\` 目录：
`https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe`

> 链接里带密码，点开即用，不用再登录。隧道随窗口关闭而失效，每次重启会换一个新域名。

## 二、它能做什么

| 能力 | 用户一句话 | 系统实际做的事 |
|---|---|---|
| **① 数据接入与结构化** | "今天血压 150/95" | 抽取数值/时间/单位 → 生理边界校验 → 写入 SQLite → 四级风险分级 |
| **①' 检验单录入** | 粘贴一张化验单的文字 | 逐项识别血糖/糖化/血脂四项 → 给出参考范围与风险等级 → **人工勾选确认后**才入库 |
| **② 趋势与预警** | "我最近血压怎么样" | 均值、极值、最小二乘斜率、超出参考范围次数 → SVG 趋势图 |
| **③ 可执行方案** | "给我一份 7 天方案" | 结合共病/会不会做饭/预算/口味/作息，生成到「几点吃什么多少克」 |
| **④ 用药联动检查** | "他汀和贝特能一起吃吗" | 40 种常用药、31 条联动规则，输出"注意什么/监测什么/问医生什么" |
| **④' 用药计划变更** | "每天早上 8 点吃一片氨氯地平" | 解析药名/剂量/时段 → **合并去重**（只补没重复的时段，不覆盖原有安排）→ 弹确认卡，确认后才写入；说"不用吃××了"同理，移除也要确认 |
| **⑤ 安全审查** | "我胸口疼得厉害" | 红旗症状命中 → 跳过一切建议生成 → 直接 120 急救指引；涉及用药的回答**强制附加**「不构成用药建议、请遵医嘱」提示条 |
| **⑥ 追踪闭环** | "帮我生成这周的报告" | 记录 + 趋势 + 依从率 + 风险事件 → 可导出的复诊报告 |

界面上还能看到 **每一步的思考过程**（安全网关 → 意图识别 → 工具调用 → 趋势分析 → 知识检索 → 生成回复），
以及每条回答下面的 **可溯源来源**（哪本指南、哪一节、哪一年）。

**界面导航**：顶部四个页签「对话 / 用药打卡 / 健康看板 / 安全说明」，侧栏四个快捷入口
（用药打卡、7 天方案、本周报告、检验单）——不用记咒语，点得到。

**适老化**：点右上角「A+」进入大字模式，**全部输出**一起放大——不只是对话气泡，
卡片数值、方案时间轴、表格、来源片段、曲线刻度、提示条都会放大到 19px 基准并加大行高；
再次进入会记住设置（`localStorage`）。系统还会响应操作系统的「减少动态效果」设置。

## 四、技术架构（五层）

```text
┌─ 交互层  Chat-first 对话 / 结构化卡片 / SVG 趋势图 / 健康看板 / 适老化大字
├─ 智能层  安全网关 → 意图识别 → 受控工具调用 → BM25 检索 → LLM 叙事 → 输出校验
├─ 知识层  11 篇指南要点 + 药物联动规则表 + 数据来源台账（可溯源、可扩充）
├─ 数据层  SQLite（测量/用药/打卡/任务/对话/风险事件）+ 检验单与对话抽取
└─ 反馈层  任务打卡 + 指标回填 → 驱动方案与趋势重算
```

**关键设计：大模型只负责"怎么说"，数字和结论全部来自工具。**
`agent/prompts.py` 把档案、工具事实、检索片段拼成受约束上下文，
并明确要求"数值必须来自事实区块，禁止自己计算"，从结构上压缩幻觉空间。

## 五、安全边界（写在代码里，不是写在提示词里）

| 层级 | 机制 | 位置 |
|---|---|---|
| 红旗症状 | 8 类急症规则 + 关键词匹配，命中即**跳过 LLM**，只输出 120 指引 | `agent/safety.py` |
| 数值急症 | 血压 ≥180/110、血糖 <3.9 或 ≥16.7、TG ≥5.6 直接判定急症 | `safety.py` + `tools/risks.py` |
| 处方红线 | 加减停换药、调剂量、自行断药 → 拒绝并给出复诊准备清单 | `safety.py::check_prescription` |
| 工具白名单 | 只有注册过的 20 个工具可被调用，模型无法"发明"能力 | `tools/registry.py` |
| 数据校验 | 生理边界 + 收缩压>舒张压，越界数据一律拒绝入库 | `tools/measurements.py::validate` |
| 引用约束 | 只能引用检索片段里出现过的来源，回答附"依据"折叠区 | `agent/prompts.py` |
| 用药提示 | 任何涉及用药的回答（联动检查 / 用药记录 / 用药清单 / 周报），由系统**结构性附加**「不构成用药建议、请严格遵医嘱」提示条，不依赖模型是否记得说 | `agent/formatter.py::med_safety_block` |
| 统一免责 | 每条回复固定附「本建议不构成诊疗意见，请遵医嘱。」 | `config.py::DISCLAIMER` |
| **会话与权限** | 用户身份只来自服务端会话，**不接受 URL 里的 `user` 参数**；未设密码时强制只监听 127.0.0.1，设置 `APP_PASSWORD` 后所有 `/api/*` 需登录（401），登录失败按 IP 限流 | `agent/auth.py` + `app.py::_require_session` |
| **打卡去重** | 按「药物 + 日期 + 计划时段」唯一，重复点击不重复计数；依从率上限 100% | `tools/medications.py::log_dose` |
| **计划变更需确认** | "每天几点吃某药""不用吃某药"→ 只生成待确认卡片，**用户点确认前不写库**；"能不能停药"仍走处方红线 | `agent/formatter.py::med_change_block` + `/api/meds/apply` |
| **未知药物拒绝** | 不在用药清单里的药不允许打卡，避免统计失真 | 同上（返回 400 + `unknown_med`） |
| **演示数据标注** | 库里含演示数据时，侧栏常驻「演示数据（合成）」提示条，可一键恢复演示数据 | `app.py::demo_info` + `ui/app.js` |
| **危险操作二次确认** | 清空全部数据必须传 `confirm=CLEAR`；评委模式下该接口直接 403 | `app.py` + `data/audit.log` |
| **档案校验** | 身高 100–220、出生年份、作息格式、文本长度等字段级校验 | `tools/profile.py::update_profile_checked` |

## 六、知识库：预留位置，随时扩充

### 6.1 三种添加方式

1. **界面拖拽**（最简单）：点左侧「知识库 → 管理」，把 `.md` / `.txt` / `.docx` 拖进虚线框
2. **直接放文件**：把文件复制到 `knowledge/docs/`，刷新页面即可（按修改时间自动热加载）
3. **调接口**：`POST /api/kb/upload?name=xxx.md`（body 为文件内容）

系统会自动解析 frontmatter 元数据、按标题层级切块、建立 BM25 索引，
并在 `knowledge/index.json` 里记录每篇文档的来源、机构、年份。

### 6.2 建议的文档格式

```markdown
---
title: 文档标题
source: 原始出处（指南全称）
org: 发布机构
year: 2024
url: https://...
level: A          # A=国家级指南 B=整理要点 C=科普
topic: 高血压      # 用于主题加权
---
# 一、章节标题
正文……
```

没有 frontmatter 也能用，只是回答里的"来源"会显示文件名。

## 十、常见问题

**Q：必须联网吗？**
A：不必须。不配置 API Key 时使用本地规则引擎，记录、趋势、方案、报告、药物联动全部可用，
只有自由问答的措辞会变成模板化表达。

**Q：数据会上传吗？**
A：不会。全部存在本地 `data/health.db`；调用大模型时只发送必要的事实摘要（不含姓名、联系方式）。

**Q：端口被占用？**
A：会自动从 8600 向后寻找可用端口，以终端打印的地址为准；也可 `python app.py --port 8800`。

**Q：为什么有时回答里没有"来源"？**
A：知识库没有命中相关片段时会明确不引用，而不是编一个来源。可以补充文档后再问。

**Q：能给别人演示吗？**
A：同一局域网内用 `python app.py --host 0.0.0.0`，把本机 IP + 端口发过去即可（注意：演示数据为合成数据）。
