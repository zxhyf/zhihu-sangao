## 四、交付方式建议

**赛段一（提交材料）**：PPT + 视频 + 代码压缩包（不含 `.env`）

**赛段二（作品链接）**：
- 首选：云主机部署（`python app.py --host 0.0.0.0 --port 80`），给出 `http://<ip>:<port>` 或绑定的域名
- 备选：本地演示 + 现场录屏，说明"零依赖，评审可一键复现"
- 注意：如果平台要求"创建评审子账号"，可在 `config.py` 中把 `DEFAULT_USER` 改为演示账号，或后续加简单的多用户隔离（当前为单用户本地模式）

**代码包结构**（压缩前确认）：

```
三高/
├─ app.py / config.py / requirements.txt / run.bat / run.ps1 / README.md
├─ agent/ tools/ data/ knowledge/ ui/ tests/ docs/
└─ 不含：.env（改为 .env.example）、__pycache__、*.log、*.db-wal
```
